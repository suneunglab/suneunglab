## 빌드
```
cd site
npm ci
npx astro build            # 콘텐츠 없이 빌드(준비 중 표시)
DATA_DIR=<YAML 폴더> npx astro build   # 콘텐츠 넣어 빌드
```
결과는 `site/dist/`(저장소에 올리지 않음).
