# data/ — 사이트 설정 데이터

02_설계 04_데이터모델 v1.0 10-1절의 설정 파일. 사이트(`site/src/lib/data.js`)가 빌드할 때 읽는다. 값은 여기 한 곳에서만 고친다.

| 파일 | 내용 | 설계 |
|---|---|---|
| `exam_years.yaml` | 학년도별 시험일·성적 통지일·확정/예상·발표일·원문 링크·트랙 제공 여부 | 04 3절 ExamYear |
| `cohorts.yaml` | 코호트(2028·2029·2030)의 고1 입학 연도·사이트 제공 기간 | 04 4절 Cohort |
| `exam_systems.yaml` | 체제 2028(2028·2029학년도): 영역별 범위·문항·시간·평가, 시험시간표, 근거 | 04 2절 ExamSystem |
| `grade_cuts.yaml` | 표준점수 기준(평균·표준편차)·등급 비율·절대평가 등급 구분 원점수(2027 기준)·최근 1등급 구분 점수 | 백로그 B-09, S6(B-12) |
| `assessment.yaml` | 영역별 내용 영역·행동 영역(평가원 공식 요소 이름)·배점·EBS 연계 — 설명은 새로 쓴 요약 | S5(B-12), 결정 19·20 |
| `schedules.yaml` | 코호트별 시험·입시 일정(학평·모평·원서·수시·수능·성적·정시, 확정은 근거 원문 필수) | T6 시험 캘린더(B-13) |
| `standards.yaml` | 성취기준 코드 → 주소 슬러그 317행(코드·과목·영역만, 문장 없음) — `tools/gen_standards.py`가 만든다 | 02 사이트맵 6절(B-13) |
| `exam_day.yaml` | 시험 당일 준비물·입실·휴대 가능/반입 금지 물품·부정행위 제재(2027학년도 기준 — 2028 유의사항 발표 전) | S7(B-12) |

- 2026-11-20 B-09에서 만들었다(계획서 58행, 11/23 과업 앞당김). 2026-11-23 B-12에서 `assessment.yaml`·`exam_day.yaml`을 더하고 `grade_cuts.yaml`에 표준점수 기준을 넣었다(계획서 61행, 11/26 과업 앞당김). 2026-11-24 B-13에서 `schedules.yaml`·`standards.yaml`을 더했다(계획서 62행, 11/27 과업 앞당김).
- '확정'은 교육부·평가원·대교협 발표가 있는 값, '예상'·'미확정'은 발표 전 값이다. 확정으로 바꿀 때는 원문 링크를 함께 넣는다(빌드가 확정인데 근거가 없으면 멈춘다).
- 이 저장소는 공개다. 비공개 자료(교과서 본문·검수 대기·예비분)는 넣지 않는다.
