# 수능랩 (suneunglab.com)

2028학년도 수능(2027-11-18 시행) 대비 학습 콘텐츠와 입시 공지를 매일 모아 보여 주는 정적 사이트의 소스 저장소.

- 사이트: Astro 정적 사이트 → Cloudflare Pages 배포
- 구성: `site/`(사이트 소스), `crawler/`(기관·대학 공지 수집), `generator/`(생성·검증 프롬프트·스크립트), `content/`(게시된 학습 콘텐츠·공지), `tools/`(커밋 전 검사 등)
- 원칙: 교과서·기출·EBS 원문은 싣지 않는다. 개념 설명·문제는 새로 쓰고 출처는 참조 표기만 한다.
- 비공개 자료(교과서 텍스트, 검수 대기 문제, 예비분, 크롤러 상태, 중복 검사 색인)는 이 저장소에 두지 않는다 — 비공개 저장소 `suneung-private`.
- 콘텐츠 라이선스: CC BY-NC-ND 4.0(설계 결정). 코드 라이선스: 미정(정하기 전까지 모든 권리 보유).
- 오류 제보: 사이트의 오류 제보 폼(댓글 없음).
